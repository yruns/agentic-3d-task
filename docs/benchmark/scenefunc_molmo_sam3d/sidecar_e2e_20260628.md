# SceneFunc MolmoPoint SAM2.1 sidecar E2E status, 2026-06-28

This record covers the repo-integrated sidecar path for the SceneFuncVal-CG
agent task:

```text
agent visual evidence
-> MolmoPoint-8B point prompt
-> agent approves point overlay
-> SAM2.1-Hiera-L mask candidates
-> agent approves contact sheet candidate
-> 2D mask to 3D fragment
-> final mask artifact
```

## Code Status

- Branch: `feat/scenefunc3d-agent-tools`
- Base: `21dc4a16ac361a474d8d119c6e44f664c4c2b050`
- Current implementation includes local HTTP sidecar clients, Molmo and SAM
  sidecar servers, deterministic 3D lifting, agent-visible artifacts, approval
  state, and a single-case runner.
- The runner now rejects fake final answers: final artifact JSON, `points_world`
  NPZ, ASCII PLY vertex counts, accepted fragment ids, and selected frame ids
  are validated before `result.json` is written.
- The agent tool loop now includes real `inspect_mask_artifact`,
  `suggest_additional_views`, and `fuse_accepted_masks` dispatch paths.
  `view_frame` exposes available depth, intrinsics, and pose paths for direct
  lifting, and `keyframe_selector` is frame-id/query aware with an explicit
  coverage-fallback strategy instead of returning the first K frames silently.
- `molmo_point` persists raw text but fails recoverably if Molmo returns no
  structured `<point>` tags, so SAM cannot run from an empty point prompt.
- The first sidecar implementation used the wrong real-model assumption for
  both heavy models: Molmo server followed old `Molmo-7B-D` style generation,
  while the available `MolmoPoint-8B` snapshot requires
  `AutoModelForImageTextToText`; SAM server followed official
  `facebookresearch/sam2` `.pt + yaml`, while the available Hiera-L cache is a
  Hugging Face `model.safetensors/config.json` snapshot.
