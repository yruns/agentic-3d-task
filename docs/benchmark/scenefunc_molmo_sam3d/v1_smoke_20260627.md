# SceneFunc Molmo SAM3D v1 smoke, 2026-06-27

This smoke checks whether the TASA-style front half can work on the local
SceneFuncVal-CG wrapper:

1. Molmo predicts a point for a small affordance target.
2. SAM turns that point into a 2D mask.
3. The 2D mask is lifted through depth + intrinsics + pose into 3D points.

Reference method: TASA describes task-aware 2D affordance detection, uses Molmo
with SAM for coarse 2D mask generation, and projects masks into 3D before a
separate geometric refinement module:

- Paper: https://arxiv.org/html/2511.11702v1
- TASA repo usage outline: https://github.com/LianHe00/TASA-main

## Script

Added:

```bash
docs/benchmark/scenefunc_molmo_sam3d/assets/molmo_sam3d_smoke.py
```

Default mode loads `allenai/Molmo-7B-D-0924`, extracts `<point x=".." y="..">`
or `(x, y)` point output, runs local SAM with that point, saves an overlay,
compressed mask, `summary.json`, and a lifted ASCII PLY.

The explicit `--manual-point x,y` diagnostic mode skips Molmo. It exists only to
test the SAM + 3D lifting half when Molmo weights are unavailable.

## Interpretation

The full requested Molmo + SAM + 3D lifting run is not yet proven because Molmo
weights could not be obtained on the worker. The reusable script is ready to
rerun once the Molmo directory is present under `/nas`.

The SAM + 3D lifting half is feasible on SceneFuncVal-CG for small objects when
the point is accurate: a single drawer knob produced a compact 2D mask and a
small lifted 3D point set. The negative cases show that a raw single point is not
robust enough by itself for all affordance targets; practical Molmo+SAM use
should add crop/box constraints, multiple points, or a post-filter that rejects
large masks before lifting.
