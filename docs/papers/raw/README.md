# Raw Codex Astra Survey Outputs

This directory preserves the unedited codex astra survey reports used to build
the polished summaries in `docs/papers/`.

- `codex_astra_3_1.md`: research point 1 (scene representation and keyframe retrieval)
- `codex_astra_3_2.md`: research point 2 (multi-task 3D reasoning)
- `codex_astra_3_3.md`: research point 3 (incremental memory and embodied execution)

These files are **research records**, not thesis text. They may contain
unverified preprint metadata, tentative venue guesses, and claims that were
later corrected during cross-checking. Do not cite them directly; use the
polished summaries and the citation metadata in `docs/papers/` instead.
