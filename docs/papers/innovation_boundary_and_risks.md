# 创新边界、遗漏文献与高风险表述

> 本文件汇总三个研究点的交叉调研结论，供论文 3.5 节、3.6 节和答辩准备使用。调研截至 2026-11-10。

## 一、可辩护的创新性

三个研究点都不宜把单项组件称为首创。可辩护的创新性应落在三个“联合”上：

1. **对象—区域双通道 + 预算约束联合覆盖 + 几何约束求解**的统一检索框架；
2. **共享表征 + 统一证据获取 + 任务特化几何核验**的三任务协同推理；
3. **增量记忆 + 程序级受保护执行 + 提交前谓词核验**的长程执行闭环。

这三条的共同点是：不是提出某个孤立模块，而是把已有组件组织成可执行、可检验、可复现的系统机制，并给出明确的接口、约束与证据链。

## 四、高风险表述与建议改法

| 原文/初稿表述 | 风险 | 建议 |
|---|---|---|
| 次模贪心 / 1−1/e 保证 | 式（17）为边际增益贪心，不保证标准次模近似 | 改为“边际增益贪心”，不声称近似比 |
| 从机制上消除检测漏检 | 网格通道仍依赖区域预测、深度有效性与预算 | 改为“降低空返回、提供区域级回退” |
| 解决视角依赖指代 | ZSVG3D 等已有直接先例；房间中心是强假设 | 改为“无共视帧条件下的确定性方位近似” |
| 无需检测标签 | 式（13）含 0.35×对象可见度 | 改为“基础可见性项不依赖检测标签，检测仅用于加权” |
| 带概率权重的假设集合 | 式（3）未实际使用 p_m | 改称“优先级权重”，或补聚合公式 |
| 统一高精度求解 | 三类任务分别调用工具，未证明知识迁移 | 改为“共享接口下的任务协同” |
| AP25 / AP50 | 实为 IoU 阈值样本比例，非官方 AP | 改称 SR@IoU / Acc@IoU，或补官方评测器 |
| 最终管线全面提升 | 平均 IoU、严格阈值指标未全面提升 | 只主张平均精确率与 F1 改善 |
| 决策耗尽率降低 = 效率提高 | 与“每轮承载更多环境步”耦合 | 补 LLM 调用数、token、动作数、墙钟与 success-per-cost |
| 有效可放置表面 | 式（32）只排除子物体遮挡 | 改称“容器交互候选掩码” |
| 完成核验 | 内部账本一致性不等于物理状态 | 明确状态来源，讨论 false positive/negative |
| SOTA / 显著优于现有方法 | AtomTree/ReAcTree 等报告更高 Unseen；Seen 下降 | 定位为“系统集成 + 运行时契约”，避免 SOTA 声明 |

## 六、建议补充的实验

1. **固定预算选帧对照**：在同一模型、同一候选序列、同一 k 下，比较 3D-Mem/MemTree3D 式检索、逐帧相关性 Top-k、对象覆盖、网格覆盖、联合覆盖。
2. **缺失参照与目标漏检拆分**：分别测试目标漏检、参照漏检、两者同时漏检；报告网格回退的精确率/召回率，而不只报告空返回率。
3. **参数敏感性**：k=1/2/5/10；δ_occ、τ_ov、λ_g、λ_id、λ_grid；锚点半径 r_A、一致度阈值 τ_agree、连通半径 ε_link。
4. **虚拟锚点与虚拟观察者分离消融**：当前合并消融无法单独归因。
5. **程序执行 2×2 消融**：仅程序、仅终止核验、二者结合、完整方法；报告 LLM 调用数、token、动作数、墙钟、恢复成功率。
6. **核验器混淆矩阵**：拦截多少错误终止、误拒绝多少已成功任务、拦截后多少真正恢复成功。
7. **ALFRED 全七类任务表**：恢复 Seen/Unseen 完整结果，补配对统计检验。
8. **公开基线匹配设置**：HLSM、FILM、MOCA、AtomTree、ReAcTree 等在不同训练/预算下的可比性说明。

## 七、建议的论文表述

> 本文不主张 BEV、场景图、虚拟视角、SAM2、Code-as-Policies、PDDL、反思或验证器等单项技术为首创。本文的创新性体现在三个“联合”上：对象—区域双通道与预算约束联合覆盖的统一检索框架；共享表征、统一证据获取与任务特化几何核验的三任务协同推理；增量记忆、程序级受保护执行与提交前谓词核验的长程执行闭环。上述机制在本文实验设置下取得一致增益，但其与已发表方法的性能边界仍需在匹配训练、预算与感知条件下进一步验证。
